# P1.c 悬浮窗权限设置指引

> 给自用版用户。第一次启用悬浮窗副驾前需要在系统设置里手动开两个权限。这是 Android 的硬性要求，App 自己开不了。

## 目的

让风格镜像副驾在你打开 Soul 时：① 自动读到对方的消息 ② 显示一个悬浮气泡 ③ 你点气泡才生成候选。**不开权限，悬浮窗功能完全用不了**（其它功能不受影响）。

我们读什么 / 不读什么：

- ✅ 仅读 **Soul 内对话页的文本**（你点气泡时才会送 LLM；你的消息绝不送）
- ❌ 不读银行 App、短信、邮件、通讯录
- ❌ 不会替你发消息（只生成候选给你复制）

## 前置

- 已装 StyleMirror（debug 或 release APK）
- 已装 Soul 并能正常聊天
- Android 6.0+

## 步骤

### 1. 开启「StyleMirror 无障碍服务」

**Why**：Android 只允许通过无障碍服务读其他 App 的界面文本。这是唯一合法路径，不开它，气泡里永远是空的。

**怎么做**：手机系统设置 → 无障碍 → 已下载的服务 → 找到 **StyleMirror** → 打开开关 → 弹窗确认「允许使用」。

**成功标志**：开关变蓝/绿；返回 StyleMirror 主页顶部的红色提醒条消失。

### 2. 允许「在其他应用上方显示」

**Why**：Android 默认禁止 App 在别的 App 上面画东西，必须单独授权。这就是悬浮气泡能浮在 Soul 之上的依据。

**怎么做**：StyleMirror 设置页 → 悬浮窗副驾区 → 「前往悬浮窗权限」按钮 → 在系统页找到 StyleMirror → 打开「允许显示在其他应用上层」。

**成功标志**：返回 StyleMirror 设置页，「悬浮窗权限」状态从 ❌ 变 ✅。

### 3. 确认 Soul 包名（一般不用动）

**Why**：少数情况下你装的 Soul 可能是非主流渠道版本，包名不是默认 `cn.soulapp.android`，需要手动填。绝大多数用户跳过这一步。

**怎么做**：打开 Soul 后再回 StyleMirror，如果气泡始终不出现：设置页 → Soul 包名 → 改成你实际的包名。**怎么看包名**：在 Soul 长按图标 → 应用信息 → 顶部那行 `cn.soul...` 就是。

**成功标志**：开 Soul 对话页 3 秒内悬浮气泡出现。

## 常见卡点

- **开关开了又自动关**：部分 ROM（小米/华为/OPPO）有"省电管理"会杀掉无障碍服务。把 StyleMirror 加入「电池白名单 / 自启动允许」。
- **气泡看不见**：检查"允许显示在其他应用上层"是否真的打开（有时点了开关但弹窗没确认）。重启 App 后再看。
- **重启手机后失效**：无障碍服务被系统重置，回到步骤 1 再开一次。这是 Android 设计如此，无解。

## 关掉怎么办

不想用了：StyleMirror 设置页 → 悬浮窗副驾 → 总开关关掉。气泡立刻消失，无障碍服务停止读取。系统权限留着也无所谓（没服务在读）。
